# ESP32_Dashboard

## Overview
ESP32_Dashboard is a project designed to display a summary of your annual Strava activities and last Strava activity

## Features
- Current date and time
- Annual distance, time and climbing in two sports (currently bike and run) (km, h, m)
- Graph of weekly and monthly mileage in rolling year (altern every hour)
- Last activity summary (Name of activity, date, distance, time, speed/pace, kudos)
- Drawing of the trace of the last activity if any
- Drawing of logo of the type of sport if no trace (currently suported bike, swim, run, racket sports)
- Streak : number of consecutive days with at least one activity


## Getting Started - NOT YET
1. Clone the repository.
2. Open the project in PlatformIO.
3. Configure your settings in `credentials.h`.
4. Build and upload to your ESP32 board.
